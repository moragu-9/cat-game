# 냥냥 사냥터

아이패드·휴대폰·PC용 반응형 고양이 터치 웹게임. 외부 라이브러리, 서버, 유료 서비스 없이 동작합니다.

## 실행

`node server.cjs` 실행 후 http://127.0.0.1:4173 에 접속합니다. 또는 index.html을 브라우저에서 엽니다. 테스트: `node rules.test.cjs`.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
공개 주소: https://moragu-9.github.io/cat-game/

## 구현 범위

- 시작, 귀엽게/징그럽게, 3단계 사냥, 700ms 길게 눌러 정지, 결과, 프로필, 로컬 전체·일간 랭킹.
- 콩벌레 10마리 → 지렁이 10마리 → 파리·지네 무제한. 동시 3/3/5마리.
- 포획 점수 10~100 반복, 연속 성공 횟수 유지. 헛터치 시 콤보 초기화. 5회 연속 실수 종료.
- pointerdown만 판정, 멀티터치 지원, 터치당 한 마리. 전환 중 입력 제외.
- 탭 비활성화·포커스 이탈 시 자동 정지. 콤보 유지, 정지·단계 안내 시간은 플레이 시간 제외.
- 기기 내 프로필 재사용, 최고 점수·날짜별 최고 기록, 동점 공동 순위, 저장 후 강조.
- 선택 사진은 중앙 정사각형 크롭 → 128×128 WebP, 20KB 이하 압축. 원본 업로드 없음.

## 시제품 기본값

3단계 파리/지네 확률 각 50%. 터치 반경 35px(지네 42px). 한국 시간 날짜 기준. 사진은 자동 중앙 크롭. 최종 벌레 디자인 전 단계의 Canvas 도형 표현입니다.

기록은 현재 브라우저 localStorage에만 보관합니다. 브라우저 데이터 삭제 시 사라집니다. 온라인 순위·다른 기기 동기화는 미구현입니다. 주소가 달라지면 별도 기록으로 저장됩니다. 실제 iPad/Safari의 발 터치 및 성능은 기기 확인이 필요합니다.
