서버 적용 순서와 운영자 신고 처리 방법은 [OPERATIONS.md](OPERATIONS.md)를 참고하세요. security.sql은 schema.sql 뒤에 적용합니다. 연속 실수 종료 기준은 100회, 이동 속도는 32/82/160px/s, 사냥감과 터치 범위는 10% 확대했습니다. 서버 검증 통합 테스트는 security.test.sql을 사용합니다.

# 최고 사냥꾼이요!

아이패드·휴대폰·PC용 고양이 터치 게임.
공개 주소: https://moragu-9.github.io/cat-game/

## 실행과 검증

로컬 실행: `node server.cjs`, http://127.0.0.1:4173 접속.
자동 검증: `node rules.test.cjs`, `node app.test.cjs`, `node online.test.cjs`.
`backend.test.sql`은 Supabase SQL Editor에서 실행하는 트랜잭션 검증이며 테스트 데이터는 rollback됩니다.

## 게임

- 나비 10마리/하늘 → 물고기 10마리/바다 → 거미 무제한/흙. 동시 3/3/5마리.
- 귀엽게: 입체 장난감 이미지. 징그럽게: 사실적인 생물 이미지.
- 포획 점수 10~100 반복, 연속 성공 횟수 유지. 헛터치 시 콤보 초기화, 연속 100회 실수 종료.
- 시작 버튼 입력은 사냥에서 제외. 손을 뗀 뒤 준비 안내가 끝나야 새로운 pointerdown을 판정합니다.
- 멀티터치, 터치당 한 마리, 길게 누르는 정지 버튼(700ms), 탭 이탈 자동 정지.
- 포획은 꽥, 실수는 삑 효과음. 첫 사용자 입력에서 Web Audio를 활성화합니다. 소리 끄기 지원.
- 포획 시 빛줄기·불꽃 입자·중앙 발광·점수 표시. 배경과 스프라이트는 렌더링용 캐시를 사용합니다.

## 온라인 랭킹

GitHub Pages + Supabase Free 프로젝트 `xcuesvegcdywlngnhlvx` (Seoul).
`config.js`에는 브라우저 공개용 publishable key만 포함합니다. 관리자/secret 키는 사용하지 않습니다.

- 익명 인증으로 기기를 식별합니다. 로그인 화면 없이 사용하며, 기기 데이터 삭제 후 소유권 복구는 지원하지 않습니다.
- 전체 및 한국 시간 기준 오늘의 최고 기록. 각 소유자의 최고 점수 하나, 동점이면 최신 기록, 최대 100개. 표시 순위는 동점 공동 순위입니다.
- `schema.sql`: RLS 활성화, 직접 테이블 접근 차단, 제한된 RPC만 허용. 닉네임 대소문자 중복 검사, 소유권 확인, 점수·단계·포획 수 검증, 중복 재전송 방지.
- 사진은 128×128 WebP 최대 20KB로 변환하며 변경 때만 전송합니다. 공개 랭킹에 닉네임·사진·기록이 노출된다고 저장 화면에 안내합니다.
- 저장 실패 시 기기에 보관하고 재전송할 수 있습니다. 게임 중에는 서버 요청이 없습니다. 이전 버전 기록은 내 기기에 보존하며 온라인에 자동 전송하지 않습니다.
- 클라이언트 점수이므로 정교한 조작 방지까지 보장하지 않습니다. 무료 서비스 한도·일시 중지 시 온라인 기능이 제한되며 로드된 게임 플레이는 계속됩니다.

## 디자인·에셋

사용자가 제공한 DESIGN.md의 흰색/파랑, 4px 모서리, 하단 inset 버튼 스타일을 적용했습니다.

- 고양이: 몸통 없는 매끈한 흰색 얼굴, 연결된 갈색 이마 무늬, 초록 눈, 작은 코와 입, 털 질감 없는 단순한 3D 비닐 장난감, 투명 배경.
- 나비: 위에서 본 파란 나비, 귀여운 3D 장난감 / 사실적인 날개 비늘과 맥의 매크로 이미지.
- 물고기: 오른쪽을 향한 노란 물고기, 둥근 3D 장난감 / 실제 비늘·지느러미를 표현한 매크로 이미지.
- 거미: 위에서 본 8개 다리 거미, 둥근 청록색 장난감 / 사실적인 갈색 늑대거미 이미지.
